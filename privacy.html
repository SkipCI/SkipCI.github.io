Privacy Policy

Last updated: 5 September 2026

SkipCI ("the application") is a private video production tool operated by Roman Neganov. This policy explains what data the application touches, why, and how long it keeps it.

1. Who runs the application

The application is run by its owner on their own machine. It has no public sign-up, no user accounts and no hosted backend that stores data for other people. The only person who connects an account to it is its operator.

2. What data the application accesses

  • Google account identity. When the operator signs in with Google, the application receives the basic profile information Google returns with the sign-in, so it can show which account is connected.
  • YouTube channel access. With the operator's consent, the application receives permission to upload videos to, and manage the metadata of, the operator's own YouTube channel.
  • Content the application itself produced. Video files, cover images, titles, descriptions and post texts generated by the pipeline.

The application does not read private messages, contacts, calendars, files in Google Drive, or any other Google data outside the scopes listed on the consent screen.

3. Why the data is used

Access is used for exactly one purpose: publishing the videos the application produced to the channel the operator connected, and reading back the status of those uploads. The data is not used for advertising, profiling, resale, model training, or any purpose unrelated to that publishing step.

4. Google API Services Limited Use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not transferred to third parties except as needed to provide the publishing feature, and is never sold.

5. Where the data is stored

OAuth tokens are stored locally on the operator's own machine, in the operator's user account, and are used only to call the Google APIs described above. Produced videos and their metadata are stored locally as well. There is no shared database and no analytics service collecting behaviour.

6. Sharing

No data is sold, rented or shared with advertisers or data brokers. Data reaches third parties only where the operator explicitly asked for publication — for example, a video uploaded to YouTube becomes subject to YouTube's own terms and privacy policy, and a post sent to Telegram becomes subject to Telegram's.

7. Retention and deletion

Tokens are kept until the operator revokes access or deletes the local credential file, whichever happens first. Produced media is kept locally for as long as the operator wants it and can be deleted at any time by deleting the files.

8. Revoking access

Access granted to the application can be withdrawn at any moment from the Google account's permission page: myaccount.google.com/permissions. Once revoked, the application can no longer reach the channel.

9. Children

The application is not directed at children and is not usable by anyone other than its operator.

10. Changes

If this policy changes, the new version is published on this page with a new date at the top.
